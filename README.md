# Customer Shopping Behavior Analysis

## Project Overview

This project analyzes customer purchasing behavior using the Brazilian E-Commerce (Olist) dataset.

The objective is to understand sales trends, customer demographics, product performance, delivery efficiency, and revenue generation through data analysis and visualization.

---

## Business Problem

E-commerce companies generate large volumes of transactional data.

This project aims to answer:

- Which products generate the most revenue?
- Which customer segments purchase the most?
- Which regions contribute the highest sales?
- How efficient are deliveries?
- What trends can help improve business performance?
